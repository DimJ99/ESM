# ESM — English · Serbian · Macedonian

Phone-first conjugation trainer. Installable as an app (PWA), works offline,
progress stays on the device.

- **Serbian**: ekavian, Latin script (č ć š ž đ)
- **Macedonian**: Cyrillic (ѓ ќ ѕ љ њ џ ј)
- 74 common verbs × present / past / future × ja·ti·on·mi·vi·oni × affirmative / negative
- Aspect pairs in both languages: perfectives drilled in past + future (pročitao sam, pročitaću · прочитав, ќе прочитам); reflexives with se / се
  (Serbian past also drilled by gender M / F / N)
- Negation done properly: *ne čitam, nisam čitao, neću čitati, nemam* · *не читам, нема да читам, немам*
- Pick Srpski, Македонски, or Mix right on the practice screen
- Hint: Serbian infinitive, Macedonian dictionary form (3sg present)
- Tracks **skills**, not flashcards: endings per tense/person (by verb class), past-tense
  gender agreement, tense formation, negation, aspect choice, and verb stems
- A wrong answer only fails the skill it points at (*pisao sam* for *pisala sam* = agreement);
  everything else in that answer counts as a success
- Each skill is spaced: 1 → 3 → 7 → 16 days, growing only when it comes back due; a miss
  shrinks it (not to zero if it was well known). Leeches = missed 4+ times on more than one day
- Prompts are built around the weakest due skill, with known skills filling the other slots,
  and avoid chaining the same tense / polarity / verb back to back
- New material is paced to keep accuracy around 70–85%
- After every answer: the full conjugation table for that tense
