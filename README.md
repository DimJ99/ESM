# ESM — English · Serbian · Macedonian

Phone-first conjugation trainer. Installable as an app (PWA), works offline,
progress stays on the device.

- **Serbian**: ekavian, Latin script (č ć š ž đ)
- **Macedonian**: Cyrillic (ѓ ќ ѕ љ њ џ ј)
- 74 common verbs × present / past / future (+ the Macedonian perfect: сум бил, тој дошол) × ja·ti·on·mi·vi·oni × affirmative / negative
- Aspect pairs in both languages: perfectives drilled in past + future (pročitao sam, pročitaću · прочитав, ќе прочитам); reflexives with se / се
  (Serbian past also drilled by gender M / F / N)
- Negation done properly: *ne čitam, nisam čitao, neću čitati, nemam* · *не читам, нема да читам, немам*
- Pick Srpski, Македонски, or **Twin** (one English prompt, answered in both languages back to back)
- Five modules, each in any language mode:
  - **Verbs** — conjugation (below)
  - **Nouns** — 117 nouns. Serbian cases through their trigger (*idem u ___ (prodavnica)* → *prodavnicu*),
    counting (*dva grada, dve kuće, pet gradova*; MK *двајца студенти, петмина браќа*), possessives (*moja sestra*); Macedonian articles
    (*столот / столов / столон*), plurals, counted forms (*два стола*), ownership (*сестра ми* / *моите пријатели*)
  - **Connectors** — fill-in-the-blank sentences (*ali / но*, *jer / затоа што*, *da / дека* …), plus a fillers list
  - **Adjectives** — agreement with real nouns: Serbian in case frames (*idem u ___ (nov · prodavnica)* → *novu prodavnicu*,
    *vidim novog profesora*), *moja nova prodavnica*, comparatives; Macedonian article on the first word
    (*новиот компјутер*, *мојот нов компјутер*), plain agreement, *по-голема куќа*
  - **Pronouns** — long vs short forms by case / role (*on → dativ, short → mu*; *тој → го*), possessives
    (*moja*, *мојата*, *мајка ми*) and drills for clitic placement, clusters (*joj ga*) and MK doubling (*Го видов Марко*)
- Hint: Serbian infinitive, Macedonian dictionary form (3sg present)
- Tracks **skills**, not flashcards: endings per tense/person (by verb class), past-tense
  gender agreement, tense formation, negation, aspect choice, and verb stems
- A wrong answer only fails the skill it points at (*pisao sam* for *pisala sam* = agreement);
  everything else in that answer counts as a success
- Each skill is spaced: 1 → 3 → 7 → 16 days, growing only when it comes back due; a miss
  shrinks it (not to zero if it was well known). Leeches = missed 4+ times on more than one day
- Prompts are built around the weakest due skill, with known skills filling the other slots,
  and avoid chaining the same tense / polarity / verb back to back
- New material is paced to keep accuracy around 70–85%
- After every answer: the full conjugation table for that tense, plus the conjugation group
- Bleed detector: the other language's word in either script (*jadam* for *jedem*) is its own tracked skill
- Answer speed is logged; a skill only reaches mastered when it's correct *and* fast
- Weekly checkpoint per language: 30 balanced questions, kept apart from practice, tracked and exportable as CSV
